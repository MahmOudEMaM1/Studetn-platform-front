# Studetn-platform-front

Student Platform frontend built with Angular.

## Development server

To start a local development server, run:

```bash
npm run dev
```

Then open `http://localhost:4200/`.

## Build

To build the project, run:

```bash
npm run build
```

The build artifacts are generated in `dist/`.

## Tests

To run tests:

```bash
npm test
```
